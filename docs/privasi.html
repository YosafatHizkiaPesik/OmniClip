Kebijakan Privasi OmniClip

Berlaku sejak 25 September 2026.

Ringkasnya

OmniClip berjalan sepenuhnya di komputer Anda. Kami tidak menjalankan server, tidak mengumpulkan data apa pun, dan tidak pernah menerima video, transkrip, maupun isi akun Google Anda.

Data yang tinggal di komputer Anda

Semuanya disimpan di folder penyimpanan yang Anda pilih sendiri:

  • Video sumber yang Anda unduh, dan klip hasil rendernya.
  • Transkrip, subtitle, dan setelan tiap klip, di dalam satu berkas basis data.
  • Riwayat pencarian dan nama akun, supaya beranda bisa menampilkan yang relevan.
  • Kunci API dan token Google yang Anda pasang sendiri.

Menghapus folder itu menghapus seluruhnya. Tidak ada salinan di tempat lain.

Layanan luar yang dihubungi, dan kapan

LayananKapan dihubungiYang dikirim
YouTube Saat Anda mencari atau mengunduh video Kata kunci dan alamat video yang Anda ketik
Google Gemini atau OpenRouter Hanya bila Anda memasang kunci API sendiri Transkrip video yang sedang diproses, untuk memilih klip dan menulis judul. Dimatikan berarti OmniClip memakai mesin lokal tanpa internet.
YouTube Data API Hanya saat Anda menekan unggah Berkas klip, judul, dan deskripsi, ke kanal Anda sendiri
Google Drive Hanya saat Anda menekan unggah Berkas klip, ke Drive Anda sendiri

Semua sambungan itu berjalan langsung dari komputer Anda ke layanan yang bersangkutan. Tidak ada yang melewati kami.

Data akun Google

  • Token akses disimpan hanya di komputer Anda, di dalam folder penyimpanan, dengan izin berkas yang dibatasi untuk pengguna Anda sendiri.
  • Alamat surel akun dipakai semata untuk menamai akun di dalam aplikasi, supaya Anda tahu akun mana yang sedang aktif.
  • Izin drive.file hanya menjangkau berkas yang dibuat OmniClip. Isi Drive Anda yang lain tidak pernah bisa dibaca aplikasi ini.
  • Anda bisa memutus sambungannya kapan saja dari halaman Akun di dalam aplikasi, atau dari halaman izin akun Google. Memutus sambungan menghapus tokennya dari komputer Anda.

Pemakaian data Google oleh OmniClip mengikuti Kebijakan Data Pengguna Layanan API Google, termasuk ketentuan Penggunaan Terbatas.

Yang tidak kami lakukan

  • Tidak ada analitik, pelacak, maupun laporan penggunaan.
  • Tidak ada data yang dijual atau dibagikan ke pihak ketiga.
  • Data Anda tidak dipakai untuk melatih model apa pun.

Anak-anak

OmniClip bukan ditujukan untuk anak di bawah 13 tahun.

Perubahan dan pertanyaan

Perubahan kebijakan ini akan tampil di halaman ini beserta tanggalnya. Pertanyaan bisa dikirim lewat halaman issue.

In English (summary)

OmniClip is a desktop application that runs entirely on the user's own computer. We operate no servers and collect no personal data whatsoever. Videos, transcripts, settings and credentials are stored only in a folder the user chooses, and deleting that folder deletes everything. The application contacts YouTube, Google Gemini or OpenRouter directly from the user's machine, and only when the user asks it to. Google account tokens never leave the user's computer. The drive.file scope grants access only to files the application itself creates. OmniClip's use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements. Users can revoke access at any time from within the application or from their Google account permissions page.
